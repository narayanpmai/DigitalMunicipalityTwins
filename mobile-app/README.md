# डिजिपालिका (DigiPalika) - Municipal Digital Twin Mobile Platform

नेपालका स्थानीय तह (गाउँपालिका तथा नगरपालिका) का लागि एकीकृत, आधुनिक र बहुउपयोगी आधिकारिक नागरिक मोबाइल एप (Cross-platform for Android & iOS)।
वर्तमान कार्यान्वयन: **पाँचपोखरी थाङपाल गाउँपालिका (डिजिपालिका)**।

---

## 📱 मुख्य सुविधाहरू (Core Features)

1. **नागरिक बडापत्र (Charter):** ११०+ सेवाको दस्तुर, कागजात, समय तालिका, आवाजमा सुन्ने (TTS), र अफलाइन हेर्न सकिने।
2. **अनलाइन ई-सिफारिस (e-Sifarish):** ३२+ सिफारिस मोबाइलबाटै फारम भर्ने, क्यामेराबाट कागजात फोटो खिच्ने र निवेदन स्थिति (Status) ट्र्याक गर्ने।
3. **स्थानीय कर तथा ई-पेमेन्ट (e-Tax):** सम्पत्ति तथा व्यवसाय कर बक्यौता हेर्ने, eSewa/Khalti/Fonepay भुक्तानी र डिजिटल मलेप १०२ रसिद।
4. **नागरिक गुनासो (Grievance):** समस्याको फोटो र जीपीएस लोकेसन सहित तत्काल दर्ता गर्ने।
5. **आपतकालीन SOS (Emergency):** एम्बुलेन्स, प्रहरी, विपद् फोकल पर्सन १-ट्याप कल, चर्को आपतकालीन साइरन र जीपीएस एसएमएस शेयर।
6. **पालिका सूचना तथा बाढी सतर्कता (Alerts):** विपद् पूर्वसूचना र सार्वजनिक क्यालेन्डर।
7. **स्मार्ट कागजात स्क्यानर तथा OCR (AI DocuScan):** नागरिकता, लालपुर्जा, सिफारिस र कर रसिद क्यामेराबाट स्क्यान, Auto Edge Detection, म्याजिक कलर/कालो-सेतो फिल्टर, Multi-Page PDF निर्माण, नेपाली देवनागरी तथा अंग्रेजी OCR अक्षर पहिचान, Word/Text निर्यात र १००% स्थानीय अफलाइन भण्डारण (Privacy-First)।
8. **एकिकृत घरधुरी सर्भे (Dynamic Survey Engine):** KoboToolbox/ODK शैलीमा निर्मित, वडागत टोलहरू (१-८), वास्तविक GPS कोर्डिनेट क्याप्चर, पारिवारिक सदस्य तालिका, खानेपानी/सरसफाइ/भवन संरचना/विपद् जोखिम, र १००% अफलाइन फिल्ड डाटा संकलन तथा सर्भर सिङ्क।
9. **पालिका ई-पुस्तकालय (Digital Palika E-Library):** ऐन तथा राजपत्र, वार्षिक नीति तथा बजेट वक्तव्य (रातो किताब), कक्षा १-८ को स्थानीय पाठ्यक्रम तथा पाठ्यपुस्तक, किसान हातेपुस्तिका, इन-एप रिडर, अफलाइन डाउनलोड र Audio TTS।
10. **सुशासन तथा सेवा केन्द्र (Citizen Services Hub):** वडागत विकास योजना ट्र्याकर (बजेट, ठेकेदार, भौतिक प्रगति बार), जनप्रतिनिधि तथा कर्मचारी डाइरेक्टरी (१-ट्याप कल)।

## 🚀 कसरी चलाउने? (Developer & Build Commands)

### १. स्थानीय रूपमा विकास/परीक्षण गर्न (Local Web Dev):
```bash
npm install
npm run dev
```
ब्राउजरमा `http://localhost:5175` खुल्नेछ। मोबाइल भ्यूमा हेर्न किबोर्डमा `F12` थिची `Device Toggle (Ctrl+Shift+M)` थिच्नुहोस्।

### २. Android Studio मा खोल्न (.apk / Play Store):
```bash
npm run cap:android
```
- एन्ड्रोइड स्टुडियो खुल्नेछ।
- त्यहाँ माथि `Build > Build Bundle(s) / APK(s) > Build APK(s)` गरी सिधै `.apk` फाइल निकाल्न सकिन्छ।
- प्ले स्टोरका लागि `Generate Signed Bundle / APK` गरी `.aab` फाइल निकाल्न सकिन्छ।

### ३. Xcode मा खोल्न (iPhone / iOS App Store):
```bash
npm run cap:ios
```
- Mac कम्प्युटरमा Xcode खुल्नेछ र सिधै App Store वा TestFlight मा पठाउन सकिन्छ।

### ४. कोड परिवर्तन गरेपछि Android/iOS मा सिङ्क गर्न:
```bash
npm run cap:sync
```
- यसले वेबको नयाँ कोड बिल्ड गरी एन्ड्रोइड र आईओएस दुवै प्रोजेक्टमा स्वतः अपडेट गरिदिन्छ।
